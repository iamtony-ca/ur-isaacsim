# EOAT CAD 데이터 인수 요청서 (STEP)

**수신**: 기구설계팀   **발신**: 로봇/시뮬레이션팀   **대상**: UR16e Dual-Tool EOAT

UR16e 로봇팔의 EOAT(엔드이펙터) 조립을 **Isaac Sim 시뮬레이션 + 실물 로봇 제어**에 사용하기 위한
CAD 데이터 인수 규격입니다. 아래 규약대로 주시면 후처리 없이 바로 시뮬레이션에 반영됩니다.

> **우선순위 안내**: 이 시뮬레이션에서 가장 중요한 것은 **UR 모션 + 그리퍼(2FG14) 파지 제어**입니다.
> copick 카메라·ESTIC 스크류드라이버는 기능 모사를 하지 않으므로 **조립된 형태로만** 주시면 됩니다.

| # | 그룹 | 형태 | 파일(제안) | 비고 |
|---|------|------|-----------|------|
| G1 | 댐퍼 + Y 듀얼 퀵체인저 | **조립 1개** | `damper_changer.step` | UR 손목(tool0) 쪽 백본, 강체 |

> base/left/right 3개로 나눠 주셔야 합니다. 나머지는 서로 고정(강체)이라 조립된 채로 주시면 됩니다.

## 2. 파일 포맷 규약

| 항목 | 요청 | 이유 |
|------|------|------|
| 포맷 | **STEP** (`.step`/`.stp`) | 정확한 솔리드. STL 은 지양(단위 정보 없음·밀도 고정) |
| STEP 버전 | **AP242** 권장 (AP214 가능) | 어셈블리 구조·메타데이터 보존 우수 |
| 단위 | **mm** | 시뮬레이션에서 자동으로 m 로 변환 |
| Up-axis | **① Z-up** 권장 / **② 차선**: 다른 축이면 어느 축인지 명시 | 축만 알면 자동 정렬 |
| 형상 | **솔리드 바디만** — 참조평면·스케치·좌표계 마커·(카메라 FOV 원뿔 등) **가상 형상 제거** | 없는 형상이 크기 계산을 오염시킴 |

> **볼트·너트 등 체결 요소품**: **조립된 채로 두셔도 됩니다.** 시뮬레이션 쪽에서 자동으로 단순화합니다.
> 굳이 빼실 필요 없습니다. (단, **눈에 띄게 돌출된 하드웨어**는 충돌 형상에 영향을 주니 남겨 주세요.)

**바디 개수 vs 형상 정밀도 — 분리해서 부탁드립니다** (이 둘은 다른 것입니다):

- **바디 개수(파일 내부 분할)**: **① 최선** — 파일당 **바디 1개**(주요 구조를 하나의 솔리드로 병합).
  **② 차선** — 어려우면 **가능한 한 적게**. 다물체여도 우리가 내부에서 병합하니 허용됩니다(로드·처리 비용만 늘어남).
  (바디를 합쳐도 **형상 정밀도는 그대로**라 정확도 손실이 없습니다.)
- **형상 정밀도**: **정확한 솔리드(B-rep) STEP** 으로 주세요 (삼각형화된 faceted STEP 아님). STEP 은 삼각형/해상도가
  없어 시뮬레이션 쪽에서 용도별(플래닝은 가볍게, 정밀 접촉 학습은 고정밀)로 **알아서 생성**하니, 밀도는 신경 안 쓰셔도 됩니다.
  **단, export 전에 접촉면의 챔퍼·필렛·미세 형상을 단순화(defeaturing)하지 말아 주세요** — 삽입·안착 접촉 거동을 좌우하고,
  한 번 지우면 복원이 안 됩니다. (나사산·각인 같은 **비접촉 cosmetic 은 빼셔도 무방**합니다.)

## 3. 좌표계(원점·축) 규약  ★ 가장 중요

각 부품의 로컬 좌표계를 아래 규약으로 맞춰 주시면 후처리 없이 바로 조립됩니다.

```
          ┌───────────┐   ← 부품 윗면 (다음 부품이 여기에 쌓임)
          │   부품     │   ↑ +Z  (장착면에 수직 = 부착/적층 방향)
          └───────────┘
      ══════════════════   ← 장착면 = 원점 z=0 (부모 부품과 맞닿는 면)
          [ 부모 부품 ]
```

**규약 (목표 로컬 좌표계):**
- **원점**: **장착면**(부모와 맞닿는 면) 위에 위치
- **+Z 축**: 장착면에 **수직**이며, 부품이 조립되어 뻗어 나가는 **부착 방향**을 향함
- **x/y**: 장착축 중심

### 요청 우선순위 — 가능하면 전체, 최소한 축은 필수

**① 1순위 (권장): 원점 좌표계 전체를 위 규약으로 맞춰 주세요.**
장착면 = 원점 **+** 축(+Z·클로킹)까지 전부. 이렇게 주시면 시뮬레이션 쪽에서 **후처리 없이 그대로**
사용하며 **가장 정확**합니다. → **모든 부품에 이 방식으로 부탁드립니다.**

**② 최소 (필수): ①이 어려운 부품은, 최소한 아래 "축"만은 반드시 맞춰 주세요.**
- **+Z 정렬**: 장착축(장착면에 수직·부착 방향)을 +Z 로. *(정 어려우면 어느 축인지 명시.)*
- **클로킹(Z축 중심 회전)**: 방향이 있는 **비대칭 부품**은 Z를 맞춰도 돌아간 방향이 중요합니다.
  - **둥근/대칭 부품**(댐퍼 등) → +Z만 맞으면 됨, 클로킹 무관
  - **그리퍼**(방향 있음) → 아래 4장 참조 (핑거 이동방향 명시)
- 이 경우 **원점의 위치(높이·중심)** 는 시뮬레이션 쪽에서 자동 보정하니, **축만** 맞으면 됩니다.

> **즉, 원점 위치까지 다 바꿔주시면 최선(①), 여의치 않으면 축(+Z·클로킹)은 필수(②)** 입니다.
> Solid Edge 2024 에서는 재모델링 없이 ① 동기식(Synchronous) 바디 이동, 또는 ② 부품을 1개짜리
> 어셈블리에 넣고 원점에 정렬 후 STEP 내보내기로 원점/축을 간단히 바꿀 수 있습니다.

## 4. 그리퍼(2FG14) 특별 요청

그리퍼는 시뮬레이션의 핵심(파지 제어)이라 정밀 인수가 필요합니다.

- **분해 제공**: `gripper_base` / `finger_left` / `finger_right` 3개 STEP.

**(가) 좌표계·클로킹**
- **① 최선 (권장)**: base·핑거를 §3 규약대로 완전히 세팅하고, 추가로 **핑거 평행이동 축이 좌표축과 정렬**되도록
  클로킹까지 맞춰 주세요 (권장: **핑거는 ±Y 방향으로 벌어짐**). → 후처리 없이 가장 정확합니다.
- **② 차선**: 전체 프레임이 어려우면, 최소한 (a) §3의 **+Z 축**, (b) **핑거 평행이동 축**, (c) **base 커넥터/케이블 방향**
  을 명시해 주세요. (원점 위치는 시뮬레이션 쪽에서 자동 보정합니다.)

**(나) 핑거 개폐 상태**
- **① 최선 (권장)**: 세 부품을 **완전 열림(full-open)** 상태로 고정 + **핑거 1개의 총 스트로크(mm)** 를 함께 명시해 주세요.
  → 조인트 0점·이동방향·리밋을 한 번에 확정. (여유되면 **완전 열림·완전 닫힘 두 상태 모두** 주시면 스트로크를
  형상에서 직접 얻어 가장 정확합니다.)
- **② 차선**: 스트로크 수치 제공이 어려우면, **한 극단(완전 열림 또는 완전 닫힘)으로 고정**하고 **어느 상태인지**만
  알려 주세요. 스트로크는 2FG14 데이터시트로 보완하겠습니다.

## 5. 물성(질량 특성) 데이터 요청  ★ 시뮬레이션 정확도의 핵심

형상만으로는 질량을 정확히 알 수 없어, **CAD 가 계산한 물성 값**을 별도 표로 받고자 합니다.
Solid Edge **Physical Properties(물리적 특성)** 로 **전체 조립(볼트·재질 밀도 포함)** 기준으로 산출해 주세요.
→ 이렇게 주시면 STEP 에 볼트가 있든 없든 물성은 정확해집니다.

> **선후 관계 안내**: **충돌 감지(우리 1차 목표)** 자체는 **형상(§2) + 좌표계(§3) + 그리퍼 조인트(§4)** 만
> 있으면 동작합니다(질량·관성 불필요). 이 §5 물성 데이터는 **물리 동역학(팔 처짐·모션 현실성)과 향후
> contact-rich RL** 용이라, 형상·좌표계보다 **나중에 주셔도** 됩니다. 다만 정확한 시뮬레이션을 위해 결국 필요합니다.

**아래 표를 채워 주세요** (링크 6개):

| 링크 | 질량 (kg) | 무게중심 COM (x, y, z) | 관성텐서 (Ixx, Iyy, Izz, Ixy, Ixz, Iyz) |
|------|-----------|------------------------|------------------------------------------|
| G1 댐퍼+체인저 |  |  |  |
| G2 FT센서(HEX) |  |  |  |
| G3 그리퍼 base |  |  |  |
| G3 finger_left |  |  |  |
| G3 finger_right |  |  |  |
| G4 스크류툴 조립 |  |  |  |

**좌표계·기준점·단위 — 최선/차선:**
- **① 최선 (권장)**: 물성을 **각 부품의 STEP export 좌표계**(= 우리 목표 링크 프레임) 기준, **관성은 무게중심(COM) 기준**,
  **SI 단위(질량 kg, COM m, 관성 kg·m²)** 로 산출해 주세요. → 변환 없이 그대로 반영, 가장 정확.
- **② 차선**: 다른 좌표계·기준점·단위여도 됩니다 — 대신 **(a) 어느 좌표계, (b) COM 기준인지 원점 기준인지,
  (c) 단위**(예: 질량 kg, COM mm, 관성 kg·mm²)를 반드시 명기해 주세요. 우리가 변환해 반영합니다.

### 추가 물리 속성 (contact-rich RL 대비) — 필수 / 강력권장 / 선택

질량·관성 외에도 Isaac Sim 은 더 많은 물리 속성을 받습니다. 최종적으로 **정밀 접촉(파지·삽입) RL** 까지
고려하므로, 아래 중 **제공 가능한 값을 모두** 주시면 정밀도가 올라갑니다. 없는 값은 시뮬레이션 쪽 표준값/튜닝으로 대체합니다.

| 구분 | 항목 | 용도 | 출처/비고 |
|------|------|------|-----------|
| **필수** | 질량(kg), 무게중심 COM(x,y,z) — 링크당 | 동역학 기본 | 위 표, CAD |
| **필수** | 그리퍼 스트로크(mm) | 핑거 조인트 리밋 | §4, 데이터시트 |
| **필수** | **핑거 파지면 재질** (고무/TPU/금속 등) | 파지 마찰 | 접촉 RL 핵심 |
| **강력권장** | 관성텐서 (Ixx, Iyy, Izz, Ixy, Ixz, Iyz) | 회전 동역학 안정성 | 없으면 box 근사(정확도↓) |
| **강력권장** | 부품별 재질 + 밀도(kg/m³) | 질량 검증·백업 | 예: STS304 ≈ 7930 |
| **강력권장** | 그리퍼 **최대 파지력(N)** | 파지 접촉력 현실화 | 2FG14 데이터시트 |
| **선택(있으면 좋음)** | 마찰계수 μ (정지/운동), 특히 파지면 | 마찰 정밀화 | 실측/시험값 |
| **선택** | 반발계수(restitution) | 충돌 반발 | 대개 낮음(금속·고무) |
| **선택** | 파지 속도(mm/s)·힘 분해능·구동방식(힘/위치) | 그리퍼 거동 | 2FG14 데이터시트 |
| **선택** | 표면 거칠기(Ra)·경도 | 마찰·마모 추정 | |
| **선택** | 핑거 조인트 마찰·댐핑, 모터 관성 | 구동부 현실화 | 없으면 sim 튜닝 |

> **핵심**: 파지·삽입 같은 **접촉 위주 학습에서 가장 중요한 물리량은 "마찰"과 "파지력"** 입니다.
> 마찰계수 실측이 어려우면 **파지면 재질만이라도** 꼭 알려 주세요(재질→마찰 추정). 나머지 선택 항목은
> 있으면 정밀도가 올라가고, 없으면 시뮬레이션 표준값으로 진행합니다.

## 6. 최종 체크리스트

- [ ] STEP(AP242 권장, 정확 B-rep), **mm** / Up-axis: ①Z-up ②(차선)축 명시 / 솔리드만(참조·가상 형상 제거, 접촉면 defeaturing 금지)
- [ ] 파일당 바디 ①1개 지향 ②(차선)가능한 한 적게 — **형상 정밀도는 원본 그대로**(단순화 금지)
- [ ] 배송 그룹 6바디 / 4파일 (그리퍼는 base+L+R 분해, 나머지 조립)
- [ ] 좌표계: **①(권장)** 원점 전체 규약대로(장착면=원점+축) / **②(최소·필수)** 축(+Z·클로킹)만은 반드시
- [ ] 그리퍼 클로킹: **①** 핑거축=+Y 정렬 / **②(차선)** 핑거 이동축·base 커넥터 방향 명시
- [ ] 그리퍼 핑거 개폐: **①** full-open + 스트로크(mm) / **②(차선)** 한 극단 고정 + 상태 통보
- [ ] 볼트 등 체결품은 조립된 채로 OK (돌출 하드웨어는 유지)
- [ ] **물성 표**(mass/COM/inertia): **①** export 좌표계·COM 기준·SI / **②(차선)** 임의 프레임 + 좌표계·기준점·단위 명기
- [ ] contact-rich 물성 — **필수**: 핑거 파지면 재질 / **강력권장**: 부품 재질·밀도, 그리퍼 최대 파지력(N) / **선택**: 마찰계수·반발계수·파지속도 등(§5 표)

문의 사항은 로봇/시뮬레이션팀으로 연락 주세요. 감사합니다.
